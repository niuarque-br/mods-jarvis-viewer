# Figuras nas cenas — plano de construção

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** cada peça das cenas pode ser desenhada com uma figura dos pacotes open-source MIT/ISC (Fluent Emoji, Tabler, Lucide, Phosphor), escolhida pelo Claude com a ferramenta `buscar_figura`, com movimento discreto. Os pedidos explícitos ("use caixas", "árvore deitada") valem acima da escolha do Claude.

**Arquitetura:**
- Um script baixa os pacotes em versões fixadas para `assets/figuras/` (fora do Git) e gera `catalogo.json`.
- O mod lê o catálogo para buscar e validar.
- O auxiliar serve as figuras sob `/<token>/figuras/`.
- A página desenha cada figura como um plano voltado para a câmera, com textura PNG ou SVG recolorido.

**Tecnologia:** a mesma do projeto. Mod em TypeScript; auxiliar em Python só com stdlib; página com three.js r170 e `node --test`. O script também é Python só com stdlib: `urllib`, `tarfile`, `zipfile`, `json` e `zlib` para ler PNG.

**Spec:** `docs/superpowers/specs/2026-10-23-figuras-design.md`. Ler antes de cada tarefa. O §9.1 traz as decisões tomadas após a revisão.

## Global Constraints

- **Repositório e branch:** `Projetos\mods-jarvis-viewer`, branch `feat/figuras`.
  - Commit por tarefa, com `git add` só nos arquivos da tarefa.
  - **Não fazer push.**
  - Antes de commitar, rodar a busca pelo nome do empregador (o termo exato está no `context.md` do workspace).
- **`assets/figuras/` fica fora do Git**, catálogo incluído (está no `.gitignore`). Nenhum arquivo de figura entra num commit.
- **Pacotes e versões fixadas:**
  - Tabler `@tabler/icons@3.49.0`;
  - `lucide-static@1.61.0`;
  - `@phosphor-icons/core@2.1.1`;
  - Fluent Emoji `microsoft/fluentui-emoji` num commit fixo, que a Tarefa 1 descobre e grava no script.
  - **Só MIT/ISC.** Noto, Twemoji e OpenMoji estão fora.
- **Formato do nome de figura:** `<pacote>/<estilo>:<id>`, com estes estilos:
  - `fluent/3d`, `fluent/color`, `fluent/flat`, `fluent/hc`;
  - `tabler/outline`, `tabler/filled`;
  - `lucide/line`;
  - `phosphor/thin|light|regular|bold|fill|duotone`.
- **Tom das figuras:**
  - `tom` ∈ `clara | escura | colorida | mono`;
  - `mono` vale para Tabler, Lucide, Phosphor e Fluent HC (recolorível);
  - `escura` é a figura colorida cuja luminância média visível fica abaixo de **0.25**.
- **Movimentos:** `girar | pulsar | balancar | subir | respirar | piscar`.
- **Campos novos na cena:**
  - `estilo.forma` aceita as formas de arquitetura (`caixa | esfera | octaedro | cilindro | pessoa | orbe`);
  - `estilo.arranjo` aceita `vertical | horizontal` e só vale em `arvore`, `fluxo` e `camadas`;
  - `estilo.figuras` é um prefixo `<pacote>/<estilo>`.
- **Textos exatos:**
  - erro de figura: `<caminho>.figura: figura "<nome>" não existe`;
  - sem catálogo: `figuras não instaladas; rode scripts/baixar-figuras.py`.
- **Regra R6 continua:** na página, o fim de passos e movimentos é medido por relógio, nunca por contagem de quadros.

## Review Focus

1. **Catálogo ausente ou corrompido:** a busca responde com o texto exato de "não instaladas"; o validador recusa só cenas que usam `figura`; o resto funciona. Testes na Tarefa 2.
2. **Figura que falha ao carregar na página** (arquivo apagado na faxina): a peça volta à forma geométrica e a cena não trava. Teste na Tarefa 5.
3. **Termo em português, com acento ou em maiúsculas** ("Banco de Dados", "engrenagem"): a busca encontra o mesmo que "database"/"gear". Teste na Tarefa 2.
4. **Pedido explícito contra a escolha do Claude:** `estilo.forma` sem `figura` na peça desenha a forma pedida; `figura` na peça vence `estilo.forma`. Teste na Tarefa 5 (precedência).
5. **Peça escura no tema escuro:** a busca põe as figuras `escura` por último e o guia orienta a evitá-las. Teste na Tarefa 2.

```json
{ "versao": 1, "gerado": "<iso>", "pacotes": { "tabler": { "versao": "3.49.0", "licenca": "MIT" }, ... },
  "figuras": [ { "nome": "fluent/3d:gear", "pacote": "fluent", "estilo": "3d", "id": "gear",
```

### Tarefa 2: Busca de figuras e ferramenta `buscar_figura`

**Files:**

- Modify: `hooks/register.tsx` (registrar a ferramenta e carregar o catálogo uma vez por sessão)

**Interfaces:**
- Consumes: o formato de `catalogo.json` da Tarefa 1.
- Produces (`hooks/figuras.ts`):

```ts
export type Figura = { nome: string; pacote: string; estilo: string; id: string; arquivo: string; titulo: string; palavras: string[]; categoria: string; conceito: string; tom: 'clara'|'escura'|'colorida'|'mono' }
export type Catalogo = { figuras: Figura[]; porNome: Map<string, Figura> }
export type Conceito = { conceito: string; titulo: string; palavras: string[]; opcoes: { nome: string; estilo: string; tom: string }[] }
export function parseCatalogo(texto: string): Catalogo | null          // null se inválido
export function buscar(cat: Catalogo, termo: string, opts?: { estilo?: string; limite?: number }): Conceito[]
export async function carregarCatalogo($: EngineInterface): Promise<Catalogo | null>   // ${$.plugin.root}/assets/figuras/catalogo.json, cache por sessão
```

- `hooks/sinonimos.ts` exporta `SINONIMOS: Record<string, string[]>`:
  - as chaves são termos em pt-BR sem acento e em minúsculas;

Inclua no mínimo: banco de dados, engrenagem, servidor, nuvem, pessoa, usuario, microfone, lupa, busca, documento, pasta, grafico, dinheiro, seguranca, cadeado, chave, ideia, foguete, relogio, tempo, email, mensagem, alerta, erro, sucesso, check, fila, rede, internet, computador, celular, codigo, robo, cerebro, livro, carrinho, entrega, empresa, equipe.
- **Relevância:**
  1. nome ou id exato;
  2. palavra-chave exata;

```js
export function motionAt(tipo, t, { intensidade = 1 })   // → { rotY, scale, dy, opacity }; período e amplitude por tipo
```
